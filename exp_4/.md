## Something about this:

A differential amplifier is an essential analog circuit used to amplify the difference between two input signals while rejecting noise that is common to both inputs.

Due to this property, it is widely used in:

Operational amplifiers

Analog signal processing systems


It provides high noise immunity and stable operation.


---

## explaination:

A CMOS differential amplifier consists of:

Two matched MOS transistors

A common source node

A tail current source


The differential input is defined as:

V_d = V_{in1} - V_{in2}

Operation:

If  increases → current through M1 increases

If  increases → current through M2 increases


For small input signals:

Both transistors operate in saturation region

The circuit behaves linearly



---

A_v = g_m * R_{out}

Where:

And:

g_m = {2I_D}/{V_{ov}}

## Total Supply Voltage

V_{total} = V_{DD} - V_{SS}

V_{total} = 0.9 - (-0.9) = 1.8V


---

## Tail Current ()

Using power relation:

P = V_{total} * I_{SS}

I_{SS} = {1.8mW}/{1.8V} = 1mA


---

## Drain Current

For balanced operation:

I_{D1} = I_{D2} =I_{SS}/{2}

I_D = 0.5mA


---

## Load Resistance ()

V_{out} = V_{DD} - I_D * R_D

Assuming:

V_{out} ~ 0V

0 = 0.9 - (0.5mA * R_D)

R_D = {0.9}/{0.5 * 10^{-3}} = 1.8k0hm

## Bias Point Calculation

Source Voltage

Given:

V_p = -0.7V

V_S = V_p = -0.7V


---

Gate Voltage

V_{G1} = V_{G2} = 0V


---

Gate-Source Voltage

V_{GS} = V_G - V_S

V_{GS} = 0 - (-0.7) = 0.7V


---

Overdrive Voltage

V_{OV} = V_{GS} - V_{th}

V_{OV} = 0.7 - 0.36 = 0.34V


---

Drain Voltage

V_D = V_{out} = 0V


---

Drain-Source Voltage

V_{DS} = V_D - V_S

V_{DS} = 0 - (-0.7) = 0.7V


---

## Saturation Condition

Condition:

V_{DS} \ge V_{OV}

0.7 \ge 0.34 \quad ✔

## Both MOSFETs are operating in saturation region

## Width Calculation

Using MOSFET equation:

I_D = \frac{1}{2} \mu_n C_{ox} \left(\frac{W}{L}\right) (V_{OV})^2

Rewriting:

W = {2 I_D *L}/{u_n C_{ox} (V_{OV})^2}

Initial calculated width:

W = 7.5 um


---

## Width Tuning and Practical Adjustment

The theoretical width is based on ideal assumptions. However, real devices show deviations.

To obtain:

V_S = -0.7V

The width is tuned through simulation.

Condition	Width

Initial	17.5 µm
Final	28.5 µm



---

## Reason for Deviation

The difference occurs due to:

Channel length modulation

Mobility degradation

Non-ideal MOSFET characteristics

Process variations

Parasitic capacitances


Hence, tuning is required.
