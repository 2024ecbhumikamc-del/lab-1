## Something about this:

A differential amplifier is an essential analog circuit used to amplify the difference between two input signals while rejecting noise that is common to both inputs.

Due to this property, it is widely used in:

Operational amplifiers

Analog signal processing systems


It provides high noise immunity and stable operation.


---

## explaination:

A CMOS differential amplifier consists of:

Two matched MOS transistors

A common source node

A tail current source


The differential input is defined as:

V_d = V_{in1} - V_{in2}

Operation:

If  increases → current through M1 increases

If  increases → current through M2 increases


For small input signals:

Both transistors operate in saturation region

The circuit behaves linearly



---

Small Signal Gain:

A_v = g_m * R_{out}

Where:

g_m = {2I_D}/{V_{ov}}

## 4.b

## Circuit 2: Differential Amplifier with PMOS Active Load

---

## Working Principle

The given circuit is composed of three main parts.  
NMOS transistors M1 and M2 form the differential pair.  
PMOS transistors M3 and M4 act as active loads.  
NMOS transistor M5 acts as the tail current source.  

When a differential input is applied, the tail current provided by M5 is divided between M1 and M2 depending on the input voltages.  

An increase in Vin1 causes M1 to conduct more current, while an increase in Vin2 causes M2 to conduct more current.  

The PMOS active load converts these current variations into voltage variations at the output nodes.  

The output is taken from the drains of M1 and M2.  

Due to the use of active load, the output resistance increases significantly, which results in higher gain.

## Working Principle

This circuit is built using an NMOS differential pair along with a current source and PMOS active loads.  

Transistors M1 and M2 form the input differential stage, while M5 provides a constant tail current.  
Transistors M3 and M4 act as load elements that convert current changes into voltage variations.  

When a differential input is applied, the current flowing through M1 and M2 changes depending on the input difference.  

If Vin1 is greater than Vin2, M1 carries more current and M2 carries less.  
If Vin2 is greater than Vin1, the opposite happens.  

These variations in current are translated into output voltage by the PMOS load transistors, enabling differential amplification.

For equal input voltages, the circuit operates in a balanced condition.  

The tail current divides equally between both branches.  

Id1 = Id2 = Iss / 2  

Substituting  

Id1 = Id2 = 1 mA / 2 = 0.5 mA

## Bias Calculation (NMOS Pair)

The source voltage is fixed at  

Vs = −0.7 V  

The gate voltage is  

Vg = 0 V  

The gate to source voltage becomes  

Vgs = Vg − Vs = 0 − (−0.7) = 0.7 V  

The overdrive voltage is obtained as  

Vov = Vgs − Vt = 0.7 − 0.36 = 0.34 V  

The drain node is at  

Vd = 0 V  

Thus  

Vds = Vd − Vs = 0 − (−0.7) = 0.7 V  

Checking saturation condition  

Vds > Vov  

0.7 > 0.34 which satisfies the requirement  

Hence, both M1 and M2 operate in saturation region.

The source terminal of M5 is connected to  

Vs = −0.9 V

Vd = −0.7 V  

Therefore  

Vds = (−0.7) − (−0.9) = 0.2 V  

To maintain saturation  

Vov is chosen approximately equal to 0.2 V  

Now  

Vgs = Vt + Vov = 0.36 + 0.2 = 0.56 V  

The gate voltage is  

Vg = Vs + Vgs = −0.9 + 0.56 = −0.34 V  

Verification condition  

Vds ≥ Vov  

0.2 ≥ 0.2 which is satisfied  

Thus, M5 operates at the boundary of saturation and provides a constant tail current.

Vs = 0.9 V

|Vtp| ≈ 0.39 V  
Vov(p) ≈ 0.25 V

Vg = Vs − Vsg = 0.9 − 0.64 = 0.26 V

Vsd > Vov
